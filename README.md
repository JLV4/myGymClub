# Project Description
myGymClub is a web-based fitness and social application designed for UIC students to build community through shared fitness activities. It allows users to track personal gym progress, set personalized goals (habitual or strength-based), log workouts, and view fitness events from the university’s recreation center. The app’s social features include sending friend requests, commenting on profiles, and gifting experience points (XP) to others. Its gamification system, inspired by Duolingo, rewards consistency through XP for workouts and event attendance, login streaks, and level progression. Overall, these elements aim to solve two common college challenges: maintaining social connections and consistent fitness habits.

Technically, myGymClub is built as a Flask web application using Python and a SQLite relational database with eleven tables. It follows a server‑rendered architecture with Jinja2 templates, supplemented by AJAX/JSON endpoints for dynamic actions like workout logging and XP gifting. A custom scraper populates events live from the UIC recreation center. XP is awarded based on goal difficulty. The front end uses Bootstrap for responsive styling and FullCalendar for an interactive calendar interface.
